# Roles in professional creature production

Studios split work by specialty. Smaller teams (and indie breedables creators) **combine roles** — but you should know what each role *means* before wearing every hat.

---

## Model / character artist

Often owns early asset creation:

| Task | Typical tools (pro) | Free route |
|------|---------------------|------------|
| Reference gathering | PureRef | PureRef personal / boards |
| Blockout / hard-surface | Maya | Blender |
| Organic sculpt | ZBrush | Blender sculpt |
| Retopology | Maya Quad Draw, TopoGun | Blender |
| UV layout | Maya, RizomUV | Blender |

**Delivers to texture/rig:** Clean low-poly mesh + UVs (+ high-poly or sculpt source).

---

## Texture / surfacing artist

Often receives approved mesh; owns surface:

| Task | Typical tools (pro) | Free route |
|------|---------------------|------------|
| Mesh baking | Substance Painter, Marmoset | Blender bake |
| PBR texture paint | Substance Painter, Mari (hero/VFX) | Blender, Krita |
| Procedural materials | Substance Designer | Material Maker |
| 2D cleanup / decals | Photoshop | Krita |
| Lookdev handoff | Marmoset Toolbag | Blender EEVEE/Cycles |

**Delivers to rig/lookdev:** Texture sets, material definitions, lookdev turntables.

---

## Technical artist / generalist (indie)

On small teams one person may span model + texture + export. **Breedables Studio default path** assumes this — but lessons are still **tagged by pipeline stage** so skills stay transferable to studio jobs.

---

## Rigger

| Task | Typical tools (pro) | Free route |
|------|---------------------|------------|
| Skeleton & controls | Maya | Blender + Rigify |
| Skin weights | Maya | Blender weight paint |
| Deformation QA | Maya | Blender test poses |

---

## Animator

| Task | Typical tools (pro) | Free route |
|------|---------------------|------------|
| Cycles, acting, game loops | Maya | Blender |
| Export to engine/SL | Pipeline-specific | Blender → SL |

---

## What changes on a breedables team

| Studio role | Breedables reality |
|-------------|-------------------|
| Separate texture artist | Often **you** — plan time for bakes + PBR |
| Engine technical artist | **SL upload + LOD + land impact** — see [SL adaptation](../second-life/adapting-professional-work.md) |
| Live ops / design | Genetics, HUD, LSL — [In-world fixture lab](../engineering/projects/in-world-fixture.md) |

---

## Why teach roles anyway

Learners watching random tutorials do not know *which* job a video assumes. Our Academy labels every lesson with **pipeline stage + role** so “texture artist workflow” vs “sculpt workflow” stays clear.
