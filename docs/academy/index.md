# Academy

!!! abstract "This section answers one question"
    *What should I learn next?*

The Academy is **routes through the wiki**, not a second copy of it. Each path is
an ordered reading list; the actual software, documentation, videos, exercises
and comparisons live on the subject pages the path links to.

That means there is exactly one page about retopology, one about PBR materials,
one about Animesh — and every path points at the same one.

## Start here

If you have never opened a 3D application, begin with the
**[Blender foundations path](paths/blender-foundations.md)**. Ten lessons take
you from installing Blender to uploading a rigged, textured creature into Second
Life. Everything else on this page assumes you have done it, or already know the
equivalent.

## What the Academy is

A complete professional creature and 3D-asset learning path that:

1. **Mirrors real pipelines.** Validated against vendor documentation, official
   training, schools such as Gnomon, and production breakdowns — not an invented
   sequence.
2. **Shows three routes at every major stage.** The professional/studio route
   (Maya, ZBrush, Substance, Mari), the free/open-source route (Blender, Material
   Maker, Krita), and the studio route — what we use now, and why. See the
   [paid vs free matrix](../research/paid-vs-free-matrix.md).
3. **Provides actual training.** Official documentation, verified video URLs,
   exercises, artifacts, and pass/fail criteria — not vague advice.
4. **Teaches correct general 3D first,** then Second Life adaptation — LOD, PBR,
   Animesh, land impact, LSL. Never bad habits justified by "SL is limited".

## What the Academy is not

- Not "learn Blender" with no links.
- Not "learn UV mapping" with no exercises.
- Not registry status labels (`GREEN`, `EXPERIMENTAL`) on learner-facing pages —
  those belong in the maintainer [tool registry](../research/tool-registry.md).
- Not another AI dashboard, RAG bot, or crawler architecture. The existing
  Librarian, daily-wiki, webscreen and Kimi stack **populates** these pages; it
  does not get replaced by new meta-systems.

## How the Academy works

1. **Evidence over watching.** Every lesson and project ends in a file committed
   to `training/`. A watched tutorial is not a completed lesson.
2. **One canonical home per topic.** Paths link; subject pages teach. If you find
   the same explanation in two places, one of them is a bug.
3. **General 3D first, Second Life second.** Learn the professional workflow, then
   learn what [Second Life](../second-life/index.md) requires you to change.
