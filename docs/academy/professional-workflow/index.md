# Professional workflow — how creature artists actually work

The Breedables Academy mirrors **real** character/creature pipelines used in games, film, and VFX — not an invented sequence.

Schools like **Gnomon** teach multi-tool workflows: e.g. game characters through **Maya + ZBrush + Substance Painter + Marmoset Toolbag**; advanced VFX texturing adds **Mari** and **Photoshop**. Creature workshops often run **reference → ZBrush → Maya → Marvelous Designer → Substance Painter**.

Our job: show that pipeline **and** how to reproduce it on a **free/open-source route** (primarily **Blender** + **Material Maker** + **Krita**) without pretending the tools are identical.

---

## Why this section exists

Beginners usually cannot answer:

- What does a **texture artist** do vs a **modeler**?
- Why would a studio pay for **ZBrush** when Blender sculpts?
- When is **Substance Painter** worth it vs Blender painting?
- What is the **whole** path from reference to game-ready creature?

Random YouTube videos rarely show the **full** professional sequence. This section does.
