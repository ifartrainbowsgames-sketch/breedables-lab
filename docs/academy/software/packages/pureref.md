## Beginner exercise

1. Create a board for one breedable species (front/side ref + 3 detail shots).  
2. Save as `.pur` in `training/references/<species>/`.  
3. Screenshot board layout in workspace.

**PASS:** Named sources, scale note, saved `.pur`, visible in screenshot.  
**FAIL:** Unlabeled Pinterest dump with no organization.
