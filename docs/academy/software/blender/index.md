# Blender Foundations — Learning Path

A sequenced path from **never opened Blender** to **exporting a rigged, textured creature that uploads and animates correctly in Second Life**. Ten lessons, each self-contained, each producing committed evidence.

This path is the skill layer under the [Academy tracks](../../overview.md). Do B01–B10 in order the first time; afterwards use them as reference. When a lesson maps to an A-track, finish the lesson, then do the track's lab for the in-world proof.

---

## What "done" looks like

After B10 you can take an idea for a breedable creature and produce, without asking in Slack:

1. A sculpted, retopologised creature mesh with sensible poly budget.
2. Clean UVs and a metallic/roughness PBR material that survives upload to SL.
3. A quadruped rig with idle + walk animations.
4. An SL upload package (mesh + LODs + physics + material) with documented land impact.

## Prerequisites for the path

- A computer that meets Blender's [minimum requirements](https://www.blender.org/download/requirements/).
- A Second Life account and viewer for the in-world checks in B07 and B10.
- Read the [content requirements](../../../studio/channel-content-requirements.md) once so you know why every lesson demands an artifact.
