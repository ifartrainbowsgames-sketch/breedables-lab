# Software & Tools — Learning Hub

This section teaches the **software** behind breedables production. The [Academy tracks A01–A05](../overview.md) are outcome labs ("make an organic PBR material", "rig a quadruped"); this section is the **skill layer underneath them** — how to actually drive Blender and the wider tool stack from zero.

If you have never opened Blender, **start here**, then take the A-tracks.

## How this fits the studio

- **Learning-first.** Every page uses the studio [lesson template](../../studio/channel-content-requirements.md) — Watch / Read / Explain / Do / Produce / Evidence. Watching a tutorial alone is **not** completion; you commit an artifact.
- **Evidence, not labels.** No `GREEN` / `EXPERIMENTAL` status theater on learner pages. See the [wiki concept audit](../../research/wiki-concept-audit.md) for why.
- **Maps to production.** Each Blender lesson names the [production line](../production-line.md) stage it serves and the A-track it feeds.
- **Registry stays secondary.** Tool license/approval detail lives in the [tools registry](../../production/tools/index.md); lessons link down to it, not the reverse.
