## How this fits the studio

- **Learning-first.** Every B-lesson uses **Watch · Read · Explain · Do · Produce · Completed when**. Watching a tutorial alone is **not** completion; you commit an artifact in `training/`.
- **Evidence, not labels.** No `GREEN` / `EXPERIMENTAL` status theater on learner pages. See the [wiki concept audit](../../research/wiki-concept-audit.md) for why.
- **Maps to production.** Each Blender lesson names the [production line](../production-line.md) stage it serves and the A-track it feeds.
- **Registry stays secondary.** Tool license/approval detail lives in the [tools registry](../../production/tools/index.md); lessons link down to it, not the reverse.
