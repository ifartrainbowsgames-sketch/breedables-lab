# Complete projects

!!! abstract "This page answers one question"
    *Which hands-on project proves I actually learned it?*

Five projects, each ending in files committed to `training/`. Watching a tutorial
does not complete a project — the evidence folder does.

## Order

Projects 1–4 can be done in any order once their subject prerequisites are met.
**Project 5 is the capstone** — it consumes the output of the other four, so do
it last.

## What "done" means

Every project has a sign-off checklist. A project counts as complete when:

1. Every artifact named in its **Produce** table exists in the repo.
2. Its sign-off checklist is fully ticked.
3. Its benchmark row in [studio experiments](../research/experiments.md) is filled in.
