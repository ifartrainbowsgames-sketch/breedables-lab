# Tutorials

!!! abstract "This section answers one question"
    *Where do I watch, without leaving the wiki?*

Every video the studio has collected lives here. The [tool pages](../tools/index.md)
still name the same videos and say why they matter — this section is where you
press play.

Nothing in this section is downloaded into the repository. YouTube plays from
YouTube. Screen-capture lessons stored on GitHub play from a CDN in front of
that repository. Closing the tab stops the stream.

!!! warning "Most of the old embedded IDs were dead"
    An audit of every YouTube id already in the wiki found **27 of 35 unique
    videos gone** — private, removed, or never valid. Players on this section
    are only the ones that still resolve. Channel and playlist links stay,
    because those keep working when a single video does not.

## How to use this section

| You want | Open |
|----------|------|
| The ten Blender lessons, in order | [Blender](blender/index.md) |
| Short silent clips that play from GitHub | [GitHub screen clips](blender/github-clips.md) |
| A specific other tool | The page named after it in the left sidebar |
| The written lesson, budgets, export settings | The **Origin** link at the top of each page |
