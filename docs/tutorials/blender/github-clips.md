# GitHub screen clips

!!! abstract "Origin"
    These clips teach Blender modelling moves that our
    [Lesson 3](../../tools/blender/mesh-modeling.md) and
    [Lesson 4](../../tools/blender/sculpting.md) assume you can do.
    The written studio rules stay on those pages.

Twenty-one silent `.webm` clips from
[sajmon170/modeling-course](https://github.com/sajmon170/modeling-course)
(AGPL-3.0). They stream from jsDelivr in front of that repository. Nothing is
copied into ours; seeking works; closing the tab stops the stream.

!!! info "Licence"
    The course is AGPL-3.0. We stream the published files and name the source.
    Do not treat the clips as studio-owned footage.

The source commit pinned here is
[`ed703a0`](https://github.com/sajmon170/modeling-course/tree/ed703a09e2b5a9f7fee96b9c4c3ec77d7ea0ed35).
