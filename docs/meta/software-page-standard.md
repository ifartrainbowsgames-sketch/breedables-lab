# Software page standard — every tool card must pass this

A registry row or a one-line tool mention is **not** an Academy software page.

**Incomplete until** sections 1–13 exist **and** section 14 (training route) has **verified URLs**.

---

## Required sections

### 1. Software name

### 2. Classification

One of:

- **OPEN SOURCE** (include exact verified license)
- **FREE / CLOSED SOURCE**
- **FREEMIUM**
- **PAID / COMMERCIAL**
- **RESEARCH ONLY**
- **OPEN CONTENT / CC0** (asset sites)

### 3. Official website

Direct clickable URL to vendor/project home.

### 4. Official download / product page

### 5. Official pricing page

Where applicable. **No hardcoded prices** without source date — link to pricing page instead.

### 6. What professionals use it for

One sentence in industry terms.  
*Example:* ZBrush → high-poly creature/character sculpting.

### 7. Where it sits in the pipeline

Link to [pipeline stage](../pipeline.md).

### 8. What it is good at

### 9. What it is not good at

### 10. Free alternative

With link to our package card if we have one.

### 11. Paid / professional alternative

### 12. Breedables Studio status

One of: **USE NOW** · **EXPERIMENTAL** · **REVIEWING** · **USE LATER** · **REJECTED**

*(Maintainers only on card footer — not learner navigation headlines.)*

### 13. Commercial / license notes

Separate:

- Application / code license  
- Model weights (if AI)  
- Bundled assets  
- Output rights  
- Plugin dependencies  

### 14. Training route (mandatory)

| Item | Required |
|------|----------|
| Official documentation | Link |
| Official beginner course | Link |
| Free video training | **Direct** video or playlist URL |
| Beginner project | Named exercise + artifact path |
| Intermediate training | When available |
| Production workflow training | When available |
| Reference manual | Link |
| Optional paid pro course | Separate section |

**Never write:** “Search YouTube for X tutorials.” **Find and verify links.**

## Lesson sequence template (per software)

For primary teach tools (e.g. Blender), each **level** includes:

```text
LEVEL N — Topic name
  Lesson title
  Video URL(s)
  Official guide URL(s)
  Exercise steps
  Expected artifact path (training/…)
  PASS criteria
  FAIL criteria (common mistakes)
```

See [Blender package card](../tools/blender/index.md) for the reference implementation.
