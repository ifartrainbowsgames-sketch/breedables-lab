## What pros use it for

Fast **retopology and baking** over high-poly sculpts — common in game character pipelines alongside Maya/Blender.

## Beginner exercise (if you have license)

Retopo a simple sculpt; compare time/quality vs Blender lesson 5.

**Artifact:** Side-by-side poly count + edge-flow notes in `training/references/topogun-comparison/`.
