## Beginner exercise

Paint a **seamless fur/skin alpha tile**; import into Blender material nodes.

**PASS:** Tileable (offset test); saved `.kra` + exported PNG in `training/texturing/krita/`  
**FAIL:** Visible seam; no source file.

Maintainers: link from [Organic PBR lab](../../projects/organic-pbr-material.md)
