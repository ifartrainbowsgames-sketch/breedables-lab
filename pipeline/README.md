# Production Pipeline

Automation and repeatable workflows that move assets from source to Second Life-ready output.

**Master map:** [Academy production line](../docs/academy/production-line.md) — stages 9–15 (export, SL upload, scripting, release).

Planned folders:

- `blender/` — Blender automation and scene setup
- `export/` — export presets and packaging
- `optimization/` — mesh, texture, and land-impact optimization
- `validation/` — pre-upload validation checks
