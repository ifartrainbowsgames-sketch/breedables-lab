# Research and R&D

Open-source-first discovery and evaluation area.

- `discoveries/` — new tools and techniques found by the R&D radar
- `experiments/` — concrete tests of promising discoveries
- `licenses/` — license/commercial-use notes
- `reports/` — research summaries and decisions

Research flow:

Discovery -> License check -> Experiment -> Decision -> Approved tool or Rejected
