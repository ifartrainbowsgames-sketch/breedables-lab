# Cat Breedable

First reference creature for the Breedables Engine.

Production areas:

- `concept/` — concept art and reference
- `blender/` — working Blender scenes
- `sculpt/` — sculpt sources
- `rig/` — Bento/Animesh rig files
- `animations/` — animation sources and exports
- `uv/` — UV layouts and unwrap files
- `textures/` — texture sources and exports
- `materials/` — PBR/material definitions
- `lod/` — optimized LOD meshes
- `collision/` — collision/physics assets
- `exports/` — Second Life-ready exports
