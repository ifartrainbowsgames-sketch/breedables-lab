# Shared Assets

Reusable project assets and their provenance.

- `cc0/` — commercially usable CC0/public-domain assets
- `references/` — visual references that must not be redistributed unless permitted
- `materials/` — reusable material sources
- `hdri/` — lighting/environment assets
- `licenses/` — license and attribution records

Never add an external asset without recording its source and usage rights.
