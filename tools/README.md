# Tool Registry

Tools discovered through R&D are tracked here before entering production.

- `approved/` — tested and approved production tools
- `experimental/` — currently being evaluated
- `rejected/` — tested and rejected, with reasons
- `blender/` — Blender-specific utilities/add-ons
- `ai/` — AI-assisted production tools
- `secondlife/` — Second Life creator utilities
- `librarian/` — Python registry, link checks, Slack lookup
- `webscreen/` — Go CLI + Chromium screening & SearXNG search ([wiki](../docs/production/tools/web-research-stack.md))

Each tool record should include license, commercial-use status, dependencies, purpose, test, result, and decision.
