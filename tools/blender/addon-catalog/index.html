    Blender add-on catalog¶

    A curated list of Blender add-ons that genuinely help the Second Life breedables pipeline, grouped by cost. For each: what it does, its relevance to breedables, and whether it is Essential or Nice-to-have for our workflow.

    Legend: ⭐ Essential for the SL breedables pipeline · ◻ Nice-to-have.

    Install built-ins via Preferences → Add-ons (search the name). Free/community add-ons install from a downloaded .zip (or, in Blender 4.2+, via the Extensions platform). Paid add-ons come from the developer or a marketplace (Superhive/Blender Market, Gumroad).

    For learning how to use these in context, see the Blender Foundations path and the tutorial arsenal.

    Built-in (ships with Blender — just enable)¶

    These are free, bundled, and stable across LTS releases. Enable them in Lesson 1.

    Add-on Cost What it does Relevance to breedables Priority
    Node Wrangler Free (built-in) Keyboard-driven shader/geo node editing (Ctrl+T, Ctrl+Shift+click preview) Massive speedup for the PBR node work in Lesson 7 and phenotype shader groups ⭐
    LoopTools Free (built-in) Extra mesh ops: Relax, Space, Circle, Bridge, Flatten Cleans edge loops on organic bases (Lesson 3) and retopo (Lesson 5) ⭐
    Rigify Free (built-in) Meta-rig → full rig generator, incl. Basic Quadruped Studio rigging baseline for Lesson 8 / Rig + animation ⭐
    glTF 2.0 importer/exporter Free (built-in) Import/export glTF/GLB with PBR materials SL PBR material upload path (Lesson 10) ⭐
    Collada (.dae) exporter Free (built-in) Export COLLADA meshes, LODs, rigs SL's mesh upload format (Lesson 10) ⭐
    Bool Tool Free (built-in) Fast boolean union/difference shortcuts Hard-surface accessories, tack, HUD props ◻
    Extra Objects (Add Mesh) Free (built-in) More primitive shapes to start from Faster blockouts and prop bases ◻
    Extra Curve Objects Free (built-in) Extra curve primitives Leashes, vines, tails-as-curves, HUD elements ◻
    Copy Attributes Menu Free (built-in) Ctrl+C to copy transforms/data between objects Speeds repetitive setup across phenotype variants ◻
    Auto Mirror Free (built-in) One-click cut-in-half + Mirror modifier Symmetric creature modeling (Lesson 3) ◻
    3D-Print Toolbox Free (built-in) Mesh checks: non-manifold, degenerate, intersecting Pre-export sanity checks before SL upload ◻

    Free / community¶

    Free (some open-source, some free-tier). Verify license before shipping anything bundled — see the tools registry.

    Add-on Cost What it does Relevance to breedables Priority
    RetopoFlow Free (GPL; also sold to support CG Cookie) Dedicated retopology toolset (guided quad drawing) Faster clean retopo for Lesson 5/Retopology; registry ⭐
    Ucupaint Free (open-source) Layer-based texture painting inside Blender Phenotype variant layers in Layered textures; registry ⭐
    TexTools Free (open-source) UV + texture utilities: align/rectify UVs, texel density, baking helpers Even texel density and quick bakes for Lesson 6/Lesson 7 ⭐
    Poly Haven Assets (GitHub) Free (assets are CC0) Browse/download CC0 HDRIs, textures, models in the Asset Browser CC0 reference materials + studio lighting; registry ⭐
    MACHIN3tools Free Modeling QoL pie menus & smart tools General modeling speed for Lesson 3 and hard-surface props ◻

    Blender 4.2+ Extensions: many of these are installable directly from the in-app Extensions browser or extensions.blender.org. Prefer that channel where available for auto-updates.

    Open source, off-catalog¶

    Not in Blender's extensions list, but GPL-compatible and worth knowing. None is studio-approved — run it past the decision model first.

    Add-on Licence What it does Why it matters here
    GameRig Open source Rigify-based auto-rigging aimed at game engines; adds rigs and metarigs Game-engine-friendly rigs are closer to what Second Life wants than a film rig
    CloudRig Open source Blender Studio's production rig-building framework The rigging system behind Blender Studio's own characters
    Rigify (upstream) GPL The add-on's development repository Where quadruped metarig behaviour is actually decided
    AutoRemesher GPLv3 Automatic all-quad retopology, with a Blender bridge An automatic first pass before manual cleanup — feed it into E03
    B-Surfaces GPL Edition GPL Draw-based modelling and retopology in Edit Mode Free alternative to RetopoFlow's stroke workflow

    Procedural and scripting¶

    For phenotype variants, one node graph beats a folder of hand-made meshes.

    Project Licence What it does
    Geometry Script Open source Write geometry node trees as Python — reviewable in git, unlike a node graph
    geonodes Open source Build geometry nodes from Python scripts
    pynodes Open source Programmatic geometry, shader and compositor nodes
    NodeToPython Open source Convert an existing node group into a Python add-on
    Sorcar Open source Node-based procedural modelling, Houdini-inspired

    Paid — but worth it¶

    Only adopt a paid add-on when it wins on measured evidence (see the tool comparison rules). These are the ones that repeatedly justify their cost for SL work.

    Add-on Cost What it does Relevance to breedables Priority
    Avastar (docs) Paid Blender add-on with the exact Second Life avatar skeleton, weighting, fitted-mesh and SL-native animation/mesh export The SL rigging/Animesh bridge — provides SL bones and .anim/mesh export that hand-rigging struggles to match. Central to Lesson 8/Lesson 10 for animated creatures ⭐
    Auto-Rig Pro (Superhive) Paid ($25 Lite / $50 Full) Fast character rigging, retargeting, skinning helpers, FBX export Speeds quadruped rigging & animation retarget for Rig + animation; pair with SL-skeleton export ◻
    UVPackmaster Paid (from ~$39) GPU/CPU high-efficiency UV packing Squeezes more texture resolution from one SL texture set (Lesson 6) — only after packing is a measured bottleneck ◻
    Zen UV Paid Full UV toolkit (marking, unwrap, stacking, texel density) Faster, more consistent unwraps for Lesson 6 ◻
    SimpleBake Paid One-click PBR + specialist map baking (AO, curvature, ID, etc.) Streamlines the sculpt→low-poly bakes in Lesson 7; Blender's built-in bake also works for free ◻
    Hard Ops / Boxcutter (site) Paid (bundle) Best-in-class hard-surface modeling & cutting Accessories, collars, HUD hardware, mechanical props — not needed for the organic creature itself ◻

    Choosing what to install (breedables shortlist)¶

    Minimum to complete the Blender Foundations path: the built-ins (Node Wrangler, LoopTools, Rigify, glTF, Collada) + free RetopoFlow, Ucupaint, TexTools, Poly Haven. That is a fully free stack.

    Add when producing animated creatures for sale: Avastar (⭐) — the one paid add-on that is hard to replace for SL Animesh.

    Add only if measured pain justifies it: UVPackmaster / Zen UV (UV throughput), SimpleBake (baking convenience), Auto-Rig Pro (rig speed), Hard Ops/Boxcutter (hard-surface accessories).
