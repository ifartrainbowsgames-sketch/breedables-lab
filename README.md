# Breedables Lab

Open-source-first production studio for building Second Life breedables.

The project is organized around one continuous workflow:

**Research -> Learn -> Experiment -> Build -> Test -> Release**

**System summary:** [docs/studio/system-build-summary.md](docs/studio/system-build-summary.md) — what we built, daily workflow, future goals.

**Roadmap:** [docs/studio-roadmap.md](docs/studio-roadmap.md) — phases 0–6 with recommended open source projects (Librarian, MkDocs, MCP RAG, ResearchShelf, Beever Atlas, etc.).

## Wiki (local)

```powershell
pip install -r requirements-docs.txt
python -m mkdocs serve -a 127.0.0.1:8765
```

Open http://127.0.0.1:8765/breedables-lab/ — browsable docs with tool links, experiments, and Second Life baseline.
