# Breedables Engine Scripts

LSL/Mono production code for the reusable Breedables Engine.

Modules:

- `core/` — identity, ownership, versioning, state
- `genetics/` — genotype storage and phenotype resolution
- `breeding/` — mating rules and offspring generation
- `lifecycle/` — age and growth states
- `movement/` — roaming, follow, home position
- `animation/` — animation state machine
- `appearance/` — mesh/material/trait presentation
- `food/` — hunger and feeding systems
- `ui/` — menus and creature interaction
- `persistence/` — state saving and recovery
- `updater/` — version/update logic
- `debug/` — developer diagnostics
